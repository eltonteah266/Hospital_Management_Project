# Hospital Management System

A Python-based command-line application designed to manage hospital appointments, patient records, doctor directories, visit notes, and payments using structured CSV data files.

## Project Structure
- main.py: Main application entry point and interactive CLI menu.
- appointments.csv: Stores appointment schedules, dates, times, and statuses.
- patients.csv: Contains patient demographics (ID, name, age, gender, phone, address).
- doctors.csv: Contains doctor directories and medical specialties.
- visits.csv: Tracks patient visit logs and clinical notes.
- payments.csv: Manages financial transactions and patient balances.

## How to Run
1. Open your terminal in the project directory.
2. Run the application using Python:
   ```bash
   python main.py
